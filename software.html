SunDevil Connect Software System

This final project was optional to do as a team, but having already participated in numerous team-based school projects while contemporaneously being constrained on time and opportunities for adequate coordination and communication, I decided to complete it alone. Although my final submission could have been vastly more polished from an aesthetic standpoint, I was proud of the degree to which I implemented each requirement given the time allotted. My project consisted of a login system (username and password creation and validation), three different access levels (student, club leader, administrator), and the following details for each level:

  • Students
    • Discover new clubs by searching for keywords or scrolling through the list of available clubs.
    • Request to join a club via button click.
    • Discover events by searching, filtering by cost and/or popularity, or scrolling through the list of all events.
    • Register for an event via button click.
    • Receive approval or denial messages/notifications regarding requests to join clubs
  • Club Leaders
    • Propose new clubs via submitting a form.
    • Approve or deny new members via a messages/notification system.
    • Post club updates by editing fields.
    • Create new events via submitting a form on the respective club page.
    • Receive approval or denial messages/notifications regarding new club proposals.
  • Administrators
    • Flag content and manage flagged content.
    • Approve or deny new clubs via a messages/notification system.

Build a REST API

Having already created a Single-File Component using Vue.js based on Q&A surveys in a previous assignment, this follow-up assignment had us create a REST API which modeled the same survey domain using Spring Boot. The survey domain included the following 4 resources: survey items, survey item instances (states: {completed; not completed}), surveys (states: {created; completed}), and survey instances (states: {created; inProgress; completed}). My completed assignment included the following HTTP methods and CRUD operations, with specific JSON formats for applicable payloads:

  1. Create a survey item (POST)
  2. Create a survey (POST)
  3. Add an existing survey item to an existing survey (PUT)
  4. Retrieve the set of all surveys (GET)
  5. Retrieve a specific survey and the set of all survey items in that survey (GET)
  6. Create a survey instance of a survey for a specific user, along with the associated set of survey item instances (POST)
  7. Retrieve the set of all survey instances in a given state (GET)
  8. Retrieve a specific survey instance, along with all of the associated survey item instances (GET)

Parallel Image Filtering

This assignment was intense. We coded in C, compiled using GCC, and ran on Xubuntu. We wrote a multi-threaded program which takes command line arguments, reads the header of an input BMP image file, and then uses a variable amount of threads to split the image into vertical columns, processed in parallel, and applied various filters to them. The first was a box blur filter where each pixel's new value is calculated based on the average of all neighboring pixel values. The second was a so-called "swiss cheese" filter, where we tinted the entire image yellowish, then created random black circles to represent "holes". The result made the image look like a slice of swiss cheese.

File Compression Idea

I had an idea for a technique for compressing binary files, and I implemented it in Python. However, contrary to my objective, the ouput file size of my algorithm ended up being larger than the input file size. Nevertheless, I still believe that there is a way to utilize my idea. The idea is based on the fact that any computer file of significant size is going to approach an average of 50% 1s and 50% 0s (on and off bits). Knowing this, by eliminating all of one type of value, you could count the occurrences of the remaining values and store them as a single integer, thereby reducing the file size by ≈50%. The problem seems to be related to the other value. Finding and documenting the pattern of occurrences of the other value results in a file size larger than the original.

Color Palette Generator

Inspired by indecision and a lack of artistic ability, I used HTML, CSS, and JavaScript to generate and display color palettes. Among other methods, I started utilizing Platonic and Archimedean solids symmetrically fitted within a cube based on the ranges of possible RGB values to determine sets of contrasting colors. For instance, this website's color palette was derived by fitting a cuboctahedron within a 16x16x16 cube, and only using colors where the cuboctahedron's vertices touch the outer cube. This is equivalent to the midpoints of all edges of the cube. The values I ultimately used were the closest shorthand form of the calculated coordinates.
